# El Messiri

Unmodified variable TrueType font from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/elmessiri

Downloaded 2026-09-08, with the accompanying SIL Open Font License in OFL.txt.
Used only for the Android chapter title, per the owner's ornamental/arabesque
typography direction. Latin chapter names remain unchanged; Norwester continues
to label the dial and short actions. No third-party font request at runtime.
