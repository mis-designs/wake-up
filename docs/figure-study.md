# Segnali e figure — first release, 2026-09-19

## Scope and sources

- Development rollout (owner follow-up): `FIGURE_STUDY_ROLLOUT = "android-preview"` in `study-quiz.js`. Only the existing explicit installed-app marker exposes Quiz per capitolo / Segnali e figure. Web retains its chapter-only entry, labels and title. A figure deep link normalizes in place on load, history navigation and page restoration, before any feature import/API read; URL/localStorage cannot opt in. Set the flag to `all` only after explicit web-release approval. This is a UI rollout, not account-private authorization: all eligible installed-app users can see it; existing server access controls remain unchanged.
- Chapter URLs remain unchanged. Trial mode keeps its existing chapter/audio entitlement and does not expose the new paid study example API.
- All186 identities come from `figure-catalog.mjs`; names, Bangla titles and source page references are not replaced by Allbooks draft translations. Asset IDs are NOT the regulatory figure numbers.
- Twelve explicit teaching groups: pericolo, precedenza, divieto, obbligo, indicazione, orizzontali, semafori/agenti, cantiere/complementari, pannelli integrativi, incroci, spie/comandi, pannelli sui veicoli. Composite images are grouped by their primary subject; e.g. danger with a distance panel stays under danger. These teaching groups are not claimed to be a complete legal taxonomy.
- Read-only consultation of Allbooks: `figures.js`, `data/figure-titles-quizpatenteapp.json`, `figure-explanation-admin.js`, `api/figure-asset.js`, its image manifest. Allbooks has ongoing unrelated edits; no Allbooks files were changed. It already uploads into the shared Magic Book explanation archive. The new consumer uses the LIVE storage listing, not the stale August manifest snapshot.
- General classification reference: [ACI, CdS article39](https://aci.gov.it/codice-della-strada/art-39/). Existing identity provenance: [published AB list](https://www.neca.it/assets/pdf/ListatoAB.pdf). Official list update entry point: [Portale dell’Automobilista](https://ilportaledellautomobilista.it/web/portale-automobilista/-/quiz-per-le-patenti-am-b-superiori-e-cqc).
- Example sentences/answers are projections of the existing normalized/corrected Magic Book chapter bank, NOT invented ministerial questions. One true and one false at most; absent polarity stays absent. Exam-only figures may have no chapter example. A false statement is never presented as the meaning of a sign. Bangla question translations appear only if already supplied; no live translation/TTS generation.
- This first release connects names, images and practice. It does not claim a freshly verified explanation/distance rule for every figure or a native-speaker approval of all existing Bengali copy. Editorial illustration quality and detailed lesson text remain subject to the owner's review.

## Integration and access

- Existing `getExplanationFigures` adds a safe `files` map derived during its already cached storage listing. Only the image-serving account/bucket may provide exact file links. Canonical `figN.webp` has priority over legacy `_0`/`_1` variants. No arbitrary R2 keys, credentials or private book content are exposed.
- `/api/asset?kind=explanation` accepts an optional exact basename only if it matches the requested figure and known image extension. Other clients keep their original fallback behavior. This avoids 4-format client probes and3 storage guesses when the manifest knows the exact filename. LastModified is a version parameter so replacing an illustration changes its cache key.
- `getFigureStudy` uses the same `ensureAccess` policy as `getStudyQuiz`, including its existing token renewal, device binding and access validation. Correct answers are already available in authenticated Study; this response is bounded to2 examples and is no-store at browser/CDN. No changes to login, payment, user state, live grading or learning-sync; self-check clicks stay in memory and do not create quiz/statistics events.

## Request budget and lifecycle

- Category navigation/search: zero API requests. Gallery: at most18 lazy figure image elements per batch, using the existing cacheable numberless asset endpoint. No full-catalog prefetch.
- First lesson: at most1 metadata request per60-second document cache window, then1 exact illustration GET only if indexed. Server listing retains its existing5-minute single-flight cache. Re-entering within the window reuses metadata; newly uploaded images may therefore take up to about6minutes to appear without a deploy.
- Examples: one authenticated read only on explicit `Prova i quiz di esempio`. Repeat openings within60seconds reuse an in-memory result. No browser storage of example answers, no polling, no automated retry loop, no per-request logs.
- A shared client read owner caps memory at16 entries, deduplicates overlapping work, sets a10-second deadline, aborts on leaving, rejects stale completions and invalidates data when the user/device changes. Failed requests do not become successful empty results. Illustration failures have a30-second automatic read cooldown; explicit Retry remains available.
- Pagehide cancels work; BFCache restoration restarts only the visible route. Unload destroys the feature's delegated listeners. Existing audio stops through its canonical Study owner when switching paths.
